## Temática
PokéManager es una aplicación basada en la franquicia ***Pokémon*** que te permite crear equipos, modificar y añadir pokemon. 

## Experiencia de usuario según el rol que tengan
En la funcionalidad de la aplicación, distinguiremos entre acciones que un administrador puede hacer dentro de la aplicación. El administrador podrá hacer acciones sobre la base de datos como eliminar pokémon, o crear nuevos.

## Problemas que se aborda
Buscamos crear una aplicación de escritorio para Windows basada en Python, la cual sería única en su mercado, ya que no existe un producto parecido de escritorio para PCs. En este caso, la mayor ventaja de ser de escritorio sería la disponibilidad sin conexión sobre todo.
